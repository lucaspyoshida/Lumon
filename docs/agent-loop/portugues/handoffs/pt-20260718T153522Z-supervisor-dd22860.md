- **Evidência:** `385.793 > 150.000` bytes.
- **Aceite:** arquivo visual final distribuído com no máximo `150.000` bytes, legibilidade/recorte aprovados e verificação automática bloqueante.

### P1 — shell sem folga/prova real

- **Evidência:** aproximação `487.673/500.000`; serviço worker, host final e shell Português futuro não estão comprovados nessa soma.
